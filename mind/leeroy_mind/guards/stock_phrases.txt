# Stock roleplay and AI phrases the guard rations (guards/phrases.py).
#
# A member may use each of these once every 3 days, and the whole cast a given one at most
# 3 times a day. A draft over either ration gets one screened rewrite whose hint names the
# phrase; see guards/README.md "Phrase cooldown".
#
# How to extend:
# - One phrase per line, as words. Case, apostrophes ("you're" = "youre") and the cast's
#   abbreviations ("u", "ur", "gonna", "rn", ...) are folded before matching, so write the
#   plain spelling once.
# - Spellings that count as the same phrase go on one line, separated by " | ". They share
#   one ration; the first one names the line in tests and reports.
# - A leading "^" matches only at the start of a sentence or a comma clause: "^at least" is
#   the consolation opener ("at least you get paid for it"), never "at least ten".
# - Matching is on whole words, so "menace" does not match "menaced".
# - Only add phrases that are stock whoever says them. An ordinary phrase a member overuses
#   is already caught by the plain cooldown, which needs no entry here.
# - Check a new entry with the replay in guards/README.md before releasing it.
